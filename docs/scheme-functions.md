# Scheme functions

Every identifier tensorlisp actually binds in the Scheme runtime, dumped from
a live boot (`(environment-symbols (interaction-environment))` and
`(library-exports '(tensorlisp))` / `'(tensorlisp runtime)` / `'(tl <name>)`
after loading the stdlib — not grepped from source, so it reflects exactly
what a program can call). Enum constants (`GGML_*`) are omitted; this is
functions only.

A program never sees these bare: it always starts `(import (tl nn) (tl
tensor) ...)`, which binds each stdlib export as `prefix:name` (or the plain
name for `(tl generic)`, or a custom rename/`only` set — see `docs/stdlib.md`
and `core.ss`'s import-form handling). The runtime-level names below (ggml
ops, `PUBLIC` helpers) are visible unprefixed to every program that can see
`(tensorlisp)` at all.

## Host-only entry points (`$tl-*`)

Exported by `(tensorlisp runtime)` but not by `(tensorlisp)` — only Rust
calls these (`crates/tensorlisp/src/scheme/mod.rs`), never program source:

```
$tl-abort-handler $tl-build $tl-call $tl-compile-generic-to-ggml
$tl-compile-generic-to-mil $tl-error-message $tl-eval-string $tl-load-program
$tl-mil-last-render $tl-pipeline $tl-postprocess $tl-preprocess $tl-protect
$tl-unload
```

Plus internal helpers `%opt %options %int %real` (option-list/number parsing
used by the ops below, exported alongside them).

## Public runtime API (`PUBLIC` in `scheme/mod.rs`)

Non-ggml functions every program can call unprefixed. Grouped by what they're
for; see `core.ss` for implementations and `docs/stdlib.md` for the layer
above these.

**Tensor introspection / graph building**
`tensor? shape strides dtype contiguous? weight weight? model inputs outputs
tap device`

**Host / preprocessing / tokenization**
`host? asset preprocess model-inputs tokenizer tokenize detokenize token-id`

**Image preprocessing**
`image-size image-resize image-resize-shortest image-resize-longest
image-resize-multiple image-center-crop image->array image-tile
image-letterbox`

**Audio preprocessing**
`audio-rate audio-length audio-resample audio-pad audio->array log-mel
whisper-features`

**Plain-array helpers** (host-side ndarray, not ggml tensors)
`array-shape array-affine array-reshape array-length array->list
list->array array-slice array-transpose array-take array-argmax`

**State (KV cache etc.)**
`define-state state effect`

**Multi-entry / pipelines / results**
`pipeline run output results postprocess`

**Detection postprocessing** (autopro `detect`)
`boxes-convert nms detect boxes-scale boxes-clip boxes-unletterbox`

**Clustering postprocessing** (autopro `cluster`)
`dbscan cluster-centroids`

**OCR postprocessing** (autopro `ocr`)
`text-boxes text-boxes-order image-crop-text ctc-greedy vocabulary
vocabulary-size vocabulary-text`

**MIL (CoreML) trace/codegen** — shadow ops + trace control, used by the
`(tl generic)` → MIL nanopass compiler
```
mil-trace:add mil-trace:silu mil-trace:sigmoid mil-trace:reshape-2d
mil-trace:reshape-3d mil-trace:reshape-4d mil-trace:ggml-concat
mil-trace:tensor-slice mil-trace:tensor-concat mil-trace:conv2d
mil-trace:conv2d-depthwise mil-trace:max-pool mil-trace:upsample-nearest
%mil-trace-reset! %mil-render %mil-render! %mil-declare-input!
```

## Stdlib libraries (`crates/tensorlisp/src/scheme/stdlib/*.ss`)

Imported as `(tl name)`; each export is bound as `name:export` unless the
import spec says `only`/`rename`/`prefix` otherwise (`(tl generic)` is the
one exception — it's meant to be imported bare, no prefix).

**`(tl tensor)`** — `tensor.ss`
`concat slice flatten as-f32 stride dim`

**`(tl nn)`** — `nn.ss`
`masked-mean sinusoidal-positions avg-pool max-pool upsample-nearest
patch-embed conv-transpose2d conv2d-depthwise conv2d gelu-tanh-exact
gelu-tanh gelu embedding rms-norm layer-norm linear`

**`(tl attn)`** — `attn.ss`
`multi-head rope sdpa merge-heads split-heads relative-mask window-mask
causal-mask padding-mask blocked`

**`(tl vision)`** — `vision.ss`
`decode-ltrb dfl anchor-grid resize-positions grid->tokens tokens->grid`

**`(tl util)`** — `util.ss`
`->integers last pad-list make-list string-join string-repeat
string-replace`

**`(tl generic)`** — `generic.ss` (bare names, no prefix; the AOT-portable
vocabulary `tensorlisp-aot` lowers to backend leaves)
`concat slice upsample-nearest max-pool conv2d-depthwise conv2d reshape
mul-mat sigmoid silu relu mul sub add`
